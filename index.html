Enviar dados.js para o GitHub

Envia o dados.js atual direto do navegador para o seu repositório (API do GitHub). Use um token fine-grained restrito a este repositório, com permissão Contents: Read and write. O token fica só nesta aba (sessionStorage) e nunca é gravado no arquivo.

Este sistema roda no GitHub Pages, que é estático: alterações feitas no navegador ficam salvas só neste navegador. Para publicar, baixe o dados.js e substitua o arquivo no repositório (commit).
